# Updates

Release notes and breaking changes for the Polkadot Products Devnet: new app
builds, runtime upgrades, redeployed contracts, and anything that requires
users or developers to act.

The newest entry is marked **Current** and is the one to act on. Older entries
stay for the record and say which update replaced them. When an update is also
discussed on the forum, the entry links to the thread.

Questions go to the Devnet developer chat on Matrix:
[#polkadot-products-public](https://matrix.to/#/#polkadot-products-public:matrix.org).
