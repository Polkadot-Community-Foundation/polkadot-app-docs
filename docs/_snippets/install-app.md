These are devnet builds. The Polkadot releases on Google Play and the App Store
connect to a different network and do not work with these docs.

| Platform | Where to get it |
| --- | --- |
| Android (recommended) | [join the tester group](https://appdistribution.firebase.dev/i/f3b79521380b40b9) to get each new build automatically |
| Android (manual APK) | the [latest Android release](https://github.com/Polkadot-Community-Foundation/polkadot-android-community/releases/latest) |
| iOS (TestFlight) | [join the TestFlight beta](https://testflight.apple.com/join/HnBX59vz) |
| Desktop (macOS / Windows / Linux) | the [latest desktop release](https://github.com/Polkadot-Community-Foundation/polkadot-desktop-community/releases/latest) |
| Web gateway (no install) | <https://dev-dot.li> |

On Android, the tester group is the easiest route. Accept the invitation with a
Google account and you are notified of each new build.

To install by hand instead, take `app-polkadot-devnet.apk` (~200 MB) from the
latest release and allow installs from unknown sources. The same APK runs with
or without Google Play services.

iOS builds are only distributed through TestFlight. The first build of each
version reaches the group once Beta App Review approves it.
