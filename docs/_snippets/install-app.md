These are **devnet** builds. The Polkadot releases on Google Play and the App
Store connect to a different network and do not work with this documentation.

| Platform | Where to get it |
| --- | --- |
| Android (recommended) | [join the tester group](https://appdistribution.firebase.dev/i/f3b79521380b40b9) — get each new build automatically |
| Android (manual APK) | the newest `devnet/…` release on the [Android releases page](https://github.com/Polkadot-Community-Foundation/polkadot-android-community/releases) |
| iOS (TestFlight) | [join the TestFlight beta](https://testflight.apple.com/join/HnBX59vz) |
| Desktop (macOS / Windows / Linux) | the newest `devnet/…` release on the [desktop releases page](https://github.com/Polkadot-Community-Foundation/polkadot-desktop-community/releases) |
| Web gateway (no install) | <https://dev-dot.li> |

On Android, joining the tester group is the easiest route: accept the invitation
with a Google account and you are notified of each new build.

To install by hand instead, take **`app-polkadot-devnet.apk`** (~200 MB) from
the newest `devnet/…` release and allow installs from unknown sources. The same
APK runs with or without Google Play services.

Older releases on these pages, including the one GitHub marks **Latest**, speak
an earlier host protocol and cannot run apps built on the current Product SDK;
take a `devnet/…` release.

iOS distribution is TestFlight-only, and the first build of each version reaches
the group once Beta App Review approves it.
